# Projeto de Refatoração de Automação

## Objetivo

Refatorar um código monolítico aplicando boas práticas de automação de testes.

## Melhorias implementadas

- Separação de responsabilidades.
- Uso de classes para Page Objects.
- Configuração centralizada.
- Massa de dados separada.
- Código modular e reutilizável.
- Testes separados por funcionalidade.
- Eliminação de variáveis globais.
- Melhor organização e manutenção do projeto.
